# ADR 0004: Web application framework

## Status
Proposed

## Context
Need `apps/web-app` and `apps/web-marketing` sharing `packages/ui` and `packages/product-frames`.

## Constraint
Must not invent layouts; must consume design tokens; marketing must import product-frames.

## Recommendation
Decide in Sprint 0–1 between Vite+React (matches existing exploration) vs Next App Router — **both allowed if shared packages remain framework-agnostic where possible**.

## Decision
Pending Frontend Lead + CTO before Sprint 1 UI stories.
